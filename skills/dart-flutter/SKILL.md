# Dart / Flutter

Use this skill for Dart / Flutter work in Event Horizon Code.

## Process

1. Resolve language pack via languages/dart/language.json.
2. Use engram_search for pinned reference records (typed absence is valid).
3. Run LSP diagnostics before test. Fix minimal change.
4. Verify arithmetic claims with calc_verify if present.

## Toolchain

- Check: dart --version, flutter --version
- LSP: dart language-server
- Build/Test/Run: flutter build / flutter test / flutter run
